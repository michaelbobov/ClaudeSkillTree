# Every skill, one map

The **Skill Tree** shows each Claude Code skill on this machine: this project's skills, your personal skills, and skills synced from claude.ai. They are grouped by category, and each one has a short description and the place it comes from.

Select a skill to read its SKILL.md, see its files, or open it in the editor. When usage tracking is on, each skill also shows how often it was used and when.

Open it from the SkillTree sidebar title, the SkillTree item in the status bar, or **SkillTree: Open Skill Tree** in the Command Palette.
