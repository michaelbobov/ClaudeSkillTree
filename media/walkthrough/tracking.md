# See which skills Claude actually uses

Usage tracking is **off** until you turn it on. When it is on, two small Claude Code hooks record the time, the skill, the session and the folder each time a skill runs, either typed as a /command or invoked by Claude.

Prompts are never recorded, and nothing leaves your machine. Turning it off restores your settings file exactly.

What you get: use counts on the Skill Tree, the last skill used in the status bar, and a timeline in **Activity**.
